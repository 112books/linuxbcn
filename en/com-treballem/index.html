How we work

  1. 01
    We listen

    We understand where the project comes from and where it wants to go. No assumptions, no pre-cooked solutions.

  2. 02
    Diagnosis

    We assess what exists, what's needed, and what's surplus. The minimum system that solves the real problem.

  3. 03
    Build

    We design and implement with free software and tools the client can maintain without us.

  4. 04
    Support

    Training and support until the system is truly theirs. Dependence on us must be minimal.

Every project starts from scratch because every situation is different. Technology comes at the end of this conversation, not at the beginning.

The technical foundation

We handle everything surrounding a digital project:

  • Domain

    Selection and management of the right domain for the project. Redirects, SSL and reputation.

  • Hosting

    The most suitable server for each project: performance, geographic location and provider values.

  • Professional email

    With your own domain, properly configured, without going through third-party servers that read your messages.

  • Social media and external platforms

    We configure and integrate them when needed, and advise on which ones make sense to use and which don't.

  • Backups

    Monitoring and automatic backups. So that a technical problem doesn't become an irreparable loss.

  • SSL certificates and basic security

    HTTPS by default, security headers, protection against common vulnerabilities.

We build to last

Systems that don’t depend on external platforms. That you can understand, modify and control. That won’t hurt you when you stop paying a subscription.
